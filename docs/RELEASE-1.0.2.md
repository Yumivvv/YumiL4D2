# v1.0.2

> 这一版主要做三件事：**把用户报的一批「点了没反应 / 删不掉 / 显示不对」逐个查到根因修掉**，
> 补上 **MOD 分类自定义**、**好友在玩头像**、**下载位置自定义**，
> 以及把网盘到期这件事从「到处现拼文案」收成一个实现。
>
> 从 v1.0.1 升级：直接覆盖 exe 即可，`data/` 目录完全兼容。

---

## 重点一：MOD 管理器终于能「自己管分类」

自动分类靠工坊 tag + 标题关键词猜，一定会判错 —— 实测「Zombie Slayer Rifle」被判成感染者
（其实是武器），「Survivor Weapon Pack」因为 tag 里有 Survivors 被判成生还者。

现在：**自动结果只是默认值，你改过的以你为准，并且记住。**

| 位置 | 能做什么 |
| --- | --- |
| MOD 详情面板的分类徽标 | 点开选择器，手动指定分类（改过的徽标带笔尖标记） |
| 左侧「分类」标题行右端 | 「+ 新建」自建分类 |
| 自建分类行右端（悬停出现） | 「⋯」→ 改名 / 删除 |
| 删掉自建分类 | **不会删 MOD**，归在它下面的回到自动分类 |

这一版为它连续修了三次，都是同一个功能的不同 bug：

- 后端方法都写好了，**QML 一次都没调用**（界面上根本没有入口）
- 「⋯」按钮被 hover 自锁 —— `cma.containsMouse` 被自己的子项抢走后
  `opacity` 和 `enabled` 同时归零，那一瞬间的点击被丢弃，表现就是「闪一下、点不动」
- **0 个 MOD 的自建分类整行不显示** —— 建完就看不见，改名/删除入口自然找不到

## 重点二：网盘到期，一个实现说了算

以前到期文案在 QML 里现拼，而且两个角标各算一套，于是同一个概念两把尺子：

| 剩余 | 旧显示 |
| --- | --- |
| 22 小时（跨了午夜） | 「1 天后到期」 |
| 10 小时（同一天） | 「今天到期」 |

现在统一按**剩余小时**分档，并且不再输出「今天到期」这种模糊说法：

| 剩余 | 显示 |
| --- | --- |
| ≥ 24 小时 | 「N 天后到期」 |
| 2～23 小时 | 「N 小时后到期」 |
| < 2 小时 | 「1 小时内到期」 |
| 已过期 / 已失效 | 「已过期」/「已失效」 |
| 永久有效 | 不显示角标 |

配套修掉的（都是真 bug，不是文案问题）：

- **「永久有效」被算成 26700 天后到期**：夸克对永久分享不是不给 `expired_at`，
  而是塞了一个固定哨兵值 `4102416000`（= **2100-01-01**）。以前拿它算天数，
  数字没错、语义全错。现在按「2100-01-01 且距现在 >40 年」认出哨兵，
  并且在接口解析、`_judge`、`expire_tag`、缓存刷新、落盘**五层**都拦住了，
  老 `library.json` 里已经存下的 26700 天也会被清掉
- **过期天数隔天不更新**（昨天 7 天、今天还是 7 天）：缓存里存的是相对天数，
  现在只存绝对时间戳，命中缓存时按此刻现算
- **百度和夸克都认了**：百度 `errno -21` 以前没映射，被说成「可能已被取消」；
  夸克过期返回的是 **HTTP 404 + code 41019**，旧代码 `status != 200` 直接 return，
  界面上一个字都不显示。现在两条都正确显示「已过期」
- **重复网盘只查上面那条**：`rec["links"]` 已有简介那一条时，置顶评论里的
  永远进不来
- **提取码跨行串号**：简介排版两种都常见，现在「同一行优先，没有才看紧邻的下一行」

## 重点三：好友在玩，现在能认出是谁

服务器页的「好友在玩」不只是名字了 —— 卡片上直接显示**好友头像**（24px 圆形）。

头像不走网络、也不要 API Key，全部读本机 Steam：

```
GetMediumFriendAvatar(sid)              → int 句柄（不是像素）
ISteamUtils::GetImageSize(句柄, &w, &h)  → 64×64
ISteamUtils::GetImageRGBA(句柄, buf, n)  → BGRA
```

三个坑（都是实测出来的）：`ISteamUtils` 不在 `ISteamFriends` 上、要从 `ISteamClient`
虚表取且**槽位是 12 而不是文档顺序的 9**（按 9 会直接崩进程）；头像是异步下载的，
第一次问常返回 0；不能每次刷新都抓（33 个好友要十几秒）—— 所以磁盘缓存优先。
圆形是在 Python 端用 Pillow 画好遮罩的，QML 只贴一张圆好的图。

顺带：好友在玩但**没收藏**的服务器，现在也会去查地图/人数/延迟了（以前只查收藏，
所以那些卡片一直「未查询」），并且可以一键收藏留住。

## 新增功能

### 下载位置可以自己定（设置 → 下载位置）
- 当前路径（等宽字体、可选可复制）、「选择文件夹…」、「恢复默认」、「打开文件夹」
- 旧目录里还有文件时，会问「要一起搬到新位置吗」—— **不自动搬**，
  几百 MB 的搬动不该被「改个设置」隐式触发
- 配置存的是「空串 = 用默认」，跟着程序目录走：绿色版整个文件夹搬走后照样有效
- 配的目录不可用时**退回默认**而不是让下载全废，但不会清空你的配置（那个盘可能只是没插）

### 导入压缩包：逐条勾选
- 拖进压缩包会自动展开、列出里面的 `.vpk`，每条标「MOD / 封面」，**默认全选**
- 点整行就能取消勾选，另有全选 / 全不选；一个都不勾就拒绝导入
- 格式从只有 `.zip` 扩到 **7z / rar / tar**（蓝奏云上大量资源是 .7z，以前拖进去被当普通文件跳过）

### 服务器：自建合集
- 新建 / 改名 / 删除 / 转入，自动合集（名字前缀、同 IP）和自建合集并存
- 转移是**移走**不是复制；自动合集被搬走一部分后不足 2 台就整组撤掉
- 删合集**只删归类，不删服务器**

### 其它
- **Ctrl+C** 复制当前选中服务器的分享文本（在搜索框里按不会被抢）
- 只填 IP 添加服务器时，**默认名取服务器自报的名字**（以前存空名，卡片上只剩一串 IP）
- 封面缓存加了软上限：超 300 MB 按最久未访问删到 220 MB 以下（实测曾堆到 320 MB / 2600 张）

## 修复

- **创意工坊「重新加载」按钮看得见、点不动**：`wsGrid` 是 `anchors.fill`、
  列表为空时仍然「可见」，把按钮的点击全吃了
- **创意工坊一直转圈**：首屏失败的收尾没清 `loading` 状态，Spinner 永远不停，
  连「加载失败」的空状态都显示不出来。现在失败分支一起清，并且给 15 秒超时；
  顶栏加了刷新按钮
- **彻底移除 STEAM API KEY**：设置里那一栏删掉了，工坊全部直连 Steam 官方
- **多选导出变成了全量导出**：`@Slot` 签名少写一个参数，QML 传的地址列表被**静默丢弃**
- **下载页「移除」不真删文件**：以前只从列表摘记录，磁盘上的文件一个都没动，
  于是越积越多。现在按类型区分 —— 下进 addons 的 MOD 只摘记录（那是你要用的），
  网盘/视频的产物连文件一起删
- **蓝奏云文件夹分享（`/bXXXX`）下不了**：以前是**主动拒绝**，压根没实现。
  现在能列文件、取直链（文件夹里的文件页是免密的，要 `websign:"2"` 且不能带 `p`）
- **扫描结果「全不选之后再勾选」勾不上、也保存不了**：QML `property var` 原地改
  同一个对象不发 changed，依赖它的按钮永远灰着
- **关闭窗口失效**：`Window.closing` 带 `QQuickCloseEvent*`，PySide6 无法转换，
  connect 不报错但触发时抛异常 —— 处理器**一次都没被调用过**
- **工坊「最新」列表只加载一页**：列表缓存没存 `hasMore`，命中缓存后退化成
  「数本页条数」，末页 28/29 条就误判到顶
- **MOD 详情简介被滚动条压住**：文字宽度现在按「真有滚动条时」扣掉滚动条宽度
- **手动改过分类后，详情面板的分类徽标多出一截空白**：笔尖图标已经算进文字宽度，
  后面又补了一次像素
- 分类「新建」按钮顶出侧边栏（`Row` + `leftPadding` 叠加撑爆布局）

## 兼容性

**Windows 10 1607 及以上**。这一版把「能不能在 Win7 上跑」查清楚了：
**不能**，而且不是改代码能解决的 —— 读了二进制的 PE 导入表，`Qt6Core.dll` 静态依赖
`WaitOnAddress`（Win8+）和 `SetThreadDescription`（Win10 1607），`python312.dll`
依赖 `CopyFile2` 等，**都在静态导入表里**，DLL 一加载就找不到符号、双击闪退。
这是 Qt 6 与 Python 3.9+ 的上游硬门槛（Qt 5.15 / Python 3.8 是最后支持 Win7 的版本）。
完整证据与降级代价见 `docs/DEVELOPMENT.md`，并留了三个可复跑的体检脚本。

## 已知问题

- 打包成 `.zip` 的工坊条目（非 `.vpk`）官方不给可用直链，会提示去工坊页面手动下载
- 工坊网页版不返回结果总数，列表只显示「已加载 N 个」
- 依赖检测（「必需物品」）仍要读工坊页面 HTML，`steamcommunity.com` 偶尔连不上，
  此时只标注「未能检查前置」，不影响下载本体
- 国内访问 GitHub / `steamcommunity.com` 不稳时，检查更新会走镜像，
  这时只拿得到版本号、拿不到详细更新日志
