> 这次更新主要做两件事：**把创意工坊彻底改成 Steam 官方接口**（回应 [issue #1](https://github.com/Yumivvv/YumiL4D2/issues/1)），

## 重点：创意工坊全部改走 Steam 官方

以前创意工坊的列表、详情、下载直链是借第三方服务换来的（会占对方自费额度）。
现在**全部直连 Steam 官方**，并且**不再需要任何 API Key**。

| 环节 | 现在走哪 |
| --- | --- |
| 列表 / 搜索 / 排序 / 筛选 | Steam 工坊网页（`workshop/browse`） |
| 详情 / 体积 / 作者 / 简介 | 官方 `GetPublishedFileDetails` |
| 下载直链 | 官方返回的 CDN 直链（`file_url`） |
| 合集判定与展开 | 官方 `GetCollectionDetails` |
| 地图中文名 | 内置表（不再查询任何在线服务） |
| CDN 节点 | 内置表 + 本地测速 |

**所以你不用再去申请 Steam API Key 了** —— 设置里那一栏已经删掉。以前填过的也自动作废，不影响使用。

顺带解释一下为什么之前那么慢：官方详情接口返回的 `file_url` 本来就是下载直链，直接拿来用即可，不必再去第三方站"换一次"。实测单条详情从 2.15 秒降到 0.66 秒。

## 新增功能

### 应用更新检查（设置 → 关于）
- 点「检查更新」查 GitHub Releases，有新版本才提示，不弹无意义的窗
- 设置里可开「启动时自动检测」
- 国内直连 GitHub 慢时会自动并发探测镜像，通常 2~4 秒出结果

### B 站登录 + 三连（点赞 / 投币 / 收藏）
- 设置里扫码登录（不需要手动填 Cookie）
- 视频详情里可以一键三连，单独控制点赞、投币、收藏、关注
- 投币失败会区分原因：**没有币**、**等级不够**、**已投过**，不再一律说"等级低"
- 设置里可开「提取到网盘链接时自动三连」（每支视频只自动一次）
- 视频作者的卡片上可以直接关注

### 服务器管理
- **批量添加 / 端口扫描**：填 `1.2.3.4` 加端口范围，一次扫一批
- **多选删除**、**多选导出配置**（导出带合集名，导入能识别）
- **拖拽 JSON 文件导入**：识别出有哪些服务器，确认后导入
- **自动分组**：同系列（名字前缀）或同 IP 的服务器自动收进一个合集
- **手动改合集名**：自动识别不准时可以自己命名
- **按名字自然排序**：`黑喵1` 排在 `黑喵10` 前面，不再是字典序
- **在线时长**字体调亮，玩家列表更好读

### MOD 管理器
- 新增「检查 MOD 文件」，可刷新工坊标签数据
- 按**导入日期**筛选；修了禁用 MOD 后列表跳回顶部的问题
- 修了创意工坊导入输入框文字溢出的问题
- 修了下载下来的工坊 MOD 没有封面的问题（超出前 60 个的会排队后台补）
- 工坊详情加载提速（单条 2.15s → 0.66s，合集走 lite 快通道）

### 其它
- **用户协议**：首次启动强制阅读，划到最底部才能勾选（10 秒倒计时）
- **视频库上限**：50 / 100 / 200 / 500 / 1000 / 不限，超了自动清理旧视频
- **蓝奏云可直接下载**：点蓝奏云链接会问你"本地下载"还是"浏览器打开"
- **网盘链接提取**：支持没有 `http://` 头部的写法（如 `pan.quark.cn/s/xxx`）
- **服务器直连**：游戏开着也能连（改用 `steam://connect`）
- **窗口圆角**：界面自己画的圆角外框；Win11 走透明合成，Win10 自动退回不透明底色

## 修复

- 「只看新的」开着但界面停在全部视频，两个状态各说各的
- 服务器列表某个合集没有战役时，切到另一个合集什么都不显示
- 服务器列表明明是战役服，分类却落在别的类别
- 合集和分类数字不一致（点进合集，分类上还显示有数字）
- 工坊封面地址被当成整包直链下载（会下成一张图）
- 简介里的网盘链接很多时，简介本身被挤没
- 滚动条拖到底却不到底（`position` 换算没归一化）
- 设置页拖不动窗口
- 换背景图/主题色后画面不刷新
- Win10 上图标全部消失（`Segoe Fluent Icons` 是 Win11 独占，已回退到 MDL2）
- Win10 上界面一片黑（无边框透明合成失败，已按版本分支处理）

## 关于 LytVPK

本项目的产品思路与部分技术方案参考了开源项目
**[LytVPK](https://github.com/LaoYutang/lytvpk)**（作者 LaoYutang），特此致谢。

参考范围：工坊浏览的分类分组与交互、MOD 加载顺序编辑器、应用更新检查的镜像方案、
CDN 优选的思路、工坊 DNS 的 CNAME 跟随规则、CDN 兜底 IP 表。
代码均为本项目用 Python + QML 独立实现。详见 README 的「致谢」一节，
以及设置 → 关于 → 致谢。

**本版本已不再调用 LytVPK 的任何线上服务**（早期版本曾默认请求其工坊列表／详情／
解析／节点池／地图名五个接口，占用对方自费额度，现全部移除）。

## 已知问题

- 打包成 `.zip` 的工坊条目（非 `.vpk`）官方不给可用直链，会提示去工坊页面手动下载
- 工坊网页版不返回结果总数，列表只显示"已加载 N 个"
- 依赖检测（"必需物品"）仍要读工坊页面 HTML，`steamcommunity.com` 偶尔连不上，
  此时只标注"未能检查前置"，不影响下载本体

- 数据（`data/` 目录）兼容，配置和视频库不会丢
